Güvenlik Hakkında Küçük Bir Not: Uygulamayı açarken Windows SmartScreen veya antivirüs "Bilinmeyen yayıncı" uyarısı verebilir, hiç endişelenmeyin! Yeni derlenen ve dijital imzası olmayan bağımsız .exe dosyalarında Windows bunu standart olarak gösterir. Uygulama tamamen yerel bilgisayarınızda çalışır, API anahtarlarınızı dışarı sızdırmaz (yalnızca kendi cihazınızda saklar) ve tüm kaynak kodu GitHub'da açıktır. Uyarı çıkarsa "Daha fazla bilgi" > "Yine de çalıştır" diyerek güvenle açabilirsiniz. Dilerseniz .exe yerine doğrudan Python kodunu inceleyip çalıştırabilirsiniz.
